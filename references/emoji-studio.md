# 表情工坊网页

本机入口：**http://127.0.0.1:4195/**。适用于用户希望上传卡通角色原图、指定多个表情的名称和描述，再下载 GIF/PNG 的任务。文件随 skill 提供，网页 assets/emoji-studio，服务 scripts/emoji_studio.py。

启动（需要 Python 3.10及以上和 Pillow）：

```bash
python3 scripts/emoji_studio.py --port 4195
```

先请求 `/api/config` 确认服务和 credential_ready，不重复启动端口。服务只监听127.0.0.1；如需开机自动启动，请自行配置本机服务。其他电脑需在本机启动；localhost地址不能发给另一台电脑直接访问。公网部署须另行确定服务器、HTTPS和访问控制；不得直接把当前本机端口公开。

## 使用流程

- 上传 PNG/JPG/WebP（最多8MB）；若本机配置了示例图片，可用示例按钮。图片身份是外形基准，可补充必须保留特征。
- 为每个表情填名称（1–24字）及具体动作描述（3–500字）。名称用于命名文件，默认不烙到图片里。默认填好10个表情的名称和描述，用户可编辑或删除，再添加自定义表情；每轮1–10个表情。
- 静态每表情1格；动态每表情12帧、占4×3格，多个表情拼在同一张合图。默认尽量一轮一张图，向模型提供身份与布局两张参考。不因布局错误强切或复制姿势凑数量。
- 本机已有历史示例会明确标注为已有素材；公开仓库不包含本机角色图片与历史任务。页面显示任务进度、历史和候选结果；可在深/浅/棋盘背景检查、拖动滑杆逐帧查看、点击图重播。
- 下载单个GIF/PNG、完整ZIP；保留原合图、提示词、透明诊断和导出帧。

## 生成接口与费用

网页当前调用 `doubao-seedream-5-0-pro-260628`，服务端读取 `ARK_API_KEY`、`ARK_API_KEY_FILE` 或 `~/.config/cartoon-character-animator/ark.key`；不把key送到浏览器，不依赖公司内部生图服务；与CLI共用 [Seedream适配器](seedream.md)。对话内imagegen工具没有可供普通网页直接调用的HTTP接口，不能声称网页用了内置imagegen。

点击生成会向模型提交一个POST。重复request_id只返回原任务；网络超时和服务重启不会自动重发付费调用。失败时保留任务和原图，由用户检查后决定是否创建新任务。一次调用不是固定金额，未接入余额查询。

数据默认保存在 `~/Library/Application Support/CartoonEmojiStudio`；通过环境变量EMOJI_STUDIO_DATA可隔离测试目录。重启时活动任务标为interrupted，历史任务可查看，不能按重启恢复的名义重复调用模型。

## 透明与微信导出

根据参考图取样选主体中不存在的背景色；保留米白、黄色和原角色颜色，不使用全局去白。生成原图、处理后蒙版与导出深浅底对照按alpha-quality.md验收，结果默认为pending_visual_review，不能把文件生成完成视为角色和表情已通过。

导出制作目标：240×240 GIF、120×120 PNG缩略图；GIF尝试降低调色板使其≤100KB，保留全部生成帧。显示实测体积和是否达到目标，不把制作目标写成已核验的微信官方当前上限。超过目标保留文件并提示；不能靠删掉帧掩盖。

可选导出2px白描边，该描边是明确选项，不是抠图残留。PNG/APNG保留半透明边缘；GIF使用二值透明。ZIP包含各GIF/PNG/APNG、缩略图和导出说明，不包含用户原始上传图片。

微信客户端自定义表情导入和微信表情开放平台上架不同。网页提供可下载文件，不自动上传微信、不声称已通过商店审核，也未生成横幅、完整专辑和赞赏材料。平台规范以官方实际上传页为准：https://sticker.weixin.qq.com/ 。
